# 📝 Django To-Do List App

A modern To-Do List web application built with **Django** and **Bootstrap 5**. Users can register, log in, manage tasks, search, filter, sort, and track their productivity through a clean dashboard.

---

## 🚀 Features

- 👤 User Registration & Login
- 🔐 Authentication (Login Required)
- ➕ Add New Tasks
- ✏️ Update Existing Tasks
- 🗑️ Delete Tasks
- ✅ Mark Tasks as Completed
- 🔍 Search Tasks
- 🎯 Filter by Priority
- 📌 Filter by Status
- ↕️ Sort Tasks
- 📄 Pagination
- 📅 Due Date Support
- 🚨 Overdue Task Highlight
- 🎨 Priority Badges
- 📊 Dashboard Statistics
- 📈 Progress Bar
- 📱 Responsive Design
- 🌟 Bootstrap Icons
- 📭 Empty State UI

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Move into Project

```bash
cd YOUR_REPOSITORY
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Create Superuser (Optional)

```bash
python manage.py createsuperuser
```

### 8. Run Development Server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
